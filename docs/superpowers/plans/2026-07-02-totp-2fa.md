# 2FA TOTP (opcjonalne, w profilu) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dodać opcjonalne, per-user dwuskładnikowe uwierzytelnianie TOTP (RFC 6238) do tmask-transporter — włączane w profilu (QR + kod potwierdzający), z dwuetapowym loginem i kodami zapasowymi na wypadek utraty urządzenia.

**Architecture:** Nowy moduł `apps/accounts/totp.py` z czystymi funkcjami (generowanie sekretu/QR, weryfikacja kodu TOTP, generowanie/weryfikacja kodów zapasowych) używanymi przez nowe widoki setup/verify/disable oraz zmodyfikowany `login_view`. Sekret TOTP przechowywany jak hasła połączeń SSH (`EncryptedCharField`), kody zapasowe jak hasła Django (zahashowane, `make_password`/`check_password`).

**Tech Stack:** Django 5.x, `pyotp` (nowa zależność), `qrcode[pil]` (nowa zależność), `django-encrypted-model-fields` (już w projekcie), pytest-django.

## Global Constraints

- Biblioteki: `pyotp==2.*`, `qrcode[pil]==8.*` w `services/web/requirements.txt` — żadnych innych pakietów 2FA (odrzucone: `django-otp`)
- Weryfikacja TOTP zawsze z `valid_window=1` (tolerancja ±30s zegara)
- Format kodu zapasowego: kanoniczna postać `XXXX-XXXX` — 8 wielkich znaków hex (`secrets.token_hex(4).upper()`) z myślnikiem po 4. znaku. Ta postać jest tym, co się hashuje i tym, co się pokazuje userowi
- Normalizacja wejścia kodu zapasowego przy weryfikacji: `strip()`, `upper()`, usunięcie istniejących myślników, wstawienie dokładnie jednego po 4. znaku
- Dokładnie 10 kodów zapasowych generowanych przy każdym włączeniu 2FA; stare kody (jeśli jakieś istniały) kasowane przy regeneracji
- Limit 5 błędnych prób kodu (TOTP lub zapasowego) na sesję pre-auth loginu — po przekroczeniu cała sesja pre-auth (`pre_2fa_*`) czyszczona
- Sekret TOTP: `EncryptedCharField` (ten sam wzorzec co `Connection.password`/`Connection.ssh_key`) — nigdy plaintext w bazie
- Kody zapasowe: `CharField` z `make_password`-hashem — nigdy plaintext w bazie
- Poza zakresem (nie implementować): reset 2FA przez admina dla innego usera, "zapamiętaj urządzenie", wymuszanie 2FA per rola, jakikolwiek wpływ na `apps/api` (tokeny API pozostają bez zmian)
- `config/settings/testing.py` używa `PASSWORD_HASHERS = ['django.contrib.auth.hashers.MD5PasswordHasher']` — szybkie hashowanie w testach, nie zmieniać

- [ ] **Step 5: Utwórz `services/web/apps/accounts/totp.py`**

```python
import base64
import secrets
from io import BytesIO

import pyotp
import qrcode
from django.contrib.auth.hashers import check_password, make_password
from django.utils import timezone

RECOVERY_CODE_COUNT = 10
ISSUER_NAME = 'tmask-transporter'


def generate_secret() -> str:
    return pyotp.random_base32()


def build_provisioning_uri(secret: str, username: str) -> str:
    return pyotp.totp.TOTP(secret).provisioning_uri(name=username, issuer_name=ISSUER_NAME)


def build_qr_data_uri(uri: str) -> str:
    img = qrcode.make(uri)
    buf = BytesIO()
    img.save(buf, format='PNG')
    encoded = base64.b64encode(buf.getvalue()).decode('ascii')
    return f'data:image/png;base64,{encoded}'


def verify_totp(secret: str, code: str) -> bool:
    return pyotp.TOTP(secret).verify(code, valid_window=1)


def normalize_recovery_code(raw: str) -> str:
    stripped = raw.strip().upper().replace('-', '')
    if len(stripped) != 8:
        return stripped
    return f'{stripped[:4]}-{stripped[4:]}'


def generate_recovery_codes(user) -> list:
    from .models import TOTPRecoveryCode

    TOTPRecoveryCode.objects.filter(user=user).delete()
    plaintext_codes = []
    for _ in range(RECOVERY_CODE_COUNT):
        raw = secrets.token_hex(4).upper()
        code = f'{raw[:4]}-{raw[4:]}'
        TOTPRecoveryCode.objects.create(user=user, code_hash=make_password(code))
        plaintext_codes.append(code)
    return plaintext_codes


def check_recovery_code(user, raw_code: str):
    from .models import TOTPRecoveryCode

    normalized = normalize_recovery_code(raw_code)
    for recovery_code in TOTPRecoveryCode.objects.filter(user=user, used_at__isnull=True):
        if check_password(normalized, recovery_code.code_hash):
            recovery_code.used_at = timezone.now()
            recovery_code.save(update_fields=['used_at'])
            return recovery_code
    return None
```
