# HTTPS (nginx self-signed cert) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve tmask-transporter over HTTPS with a self-signed certificate, redirecting all HTTP traffic to HTTPS, with Django cookies correctly marked `Secure`.

**Architecture:** nginx gets a second `server` block on port 443 with a self-signed cert (generated once, manually, outside the container lifecycle); the existing port-80 block becomes a pure 301 redirect. Django gains `SECURE_PROXY_SSL_HEADER` so it correctly recognizes HTTPS requests forwarded by nginx (which already sends `X-Forwarded-Proto`).

**Tech Stack:** nginx (stable-alpine), OpenSSL, Django 5.x, Docker Compose.

## Global Constraints

- Certificate SAN must be exactly: `tmask-transporter.local`, `localhost`, `127.0.0.1` — no more, no less (per spec decision #2).
- Certificate validity: 3650 days (10 years), generated once, never regenerated automatically by any container startup script.
- `nginx/certs/` must be gitignored — the private key must never be committed.
- Port 80 becomes a pure redirect (`return 301 https://$host$request_uri;`) — no other logic on that port.
- Do NOT add `SECURE_SSL_REDIRECT` to Django settings (nginx already handles the redirect — spec decision #4, avoids double-redirect risk with a future reverse proxy).
- Do NOT add HSTS headers (spec decision #4 — deferred until a trusted cert is in place).
- `SESSION_COOKIE_SECURE = True` and `CSRF_COOKIE_SECURE = True` **already exist in `services/web/config/settings/production.py`** (verified in the repo — the spec assumed they needed adding to `base.py`, but they were already present in `production.py`, which is the settings module actually used by the `web`/`worker`/`beat` Docker services). Task 3 only needs to ADD `SECURE_PROXY_SSL_HEADER` there — do not duplicate the cookie flags.
- `services/web/config/settings/testing.py` does **not** inherit from `base.py` or `production.py` (it's a fully standalone SQLite settings module with no `from .base import *`) — it is entirely unaffected by any change in this plan. No test-settings adjustment is needed.

**Interfaces:**

- [ ] **Step 1: Add `nginx/certs/` to `.gitignore`**

In `.gitignore`, add a new line after `.worktrees/`:
```
.worktrees/
nginx/certs/
```

- [ ] **Step 2: Generate the certificate**

Run from the repo root:
```bash
mkdir -p nginx/certs
openssl req -x509 -nodes -newkey rsa:2048 \
  -keyout nginx/certs/selfsigned.key -out nginx/certs/selfsigned.crt \
  -days 3650 -subj "/CN=tmask-transporter.local" \
  -addext "subjectAltName=DNS:tmask-transporter.local,DNS:localhost,IP:127.0.0.1"
```
Expected: two files created, `nginx/certs/selfsigned.key` (600 or default umask perms) and `nginx/certs/selfsigned.crt`, no errors printed.

- [ ] **Step 3: Verify the certificate SAN and expiry**

Run:
```bash
openssl x509 -in nginx/certs/selfsigned.crt -noout -text | grep -A1 "Subject Alternative Name"
openssl x509 -in nginx/certs/selfsigned.crt -noout -dates
```
Expected: `DNS:tmask-transporter.local, DNS:localhost, IP Address:127.0.0.1` and a `notAfter` date roughly 10 years from today.

### Task 2: nginx HTTPS server block + HTTP redirect + docker-compose wiring

**Files:**
- Modify: `nginx/nginx.conf`
- Modify: `docker-compose.yml:93-104`

**Interfaces:**
- Consumes: `nginx/certs/selfsigned.crt` / `selfsigned.key` (Task 1, mounted read-only into the container at `/etc/nginx/certs/`).

- [ ] **Step 1: Rewrite `nginx/nginx.conf`**

Replace the entire file content with:
```nginx
server {
    listen 80;
    server_name _;
    server_tokens off;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name _;
    server_tokens off;

    ssl_certificate     /etc/nginx/certs/selfsigned.crt;
    ssl_certificate_key /etc/nginx/certs/selfsigned.key;
    ssl_protocols       TLSv1.2 TLSv1.3;

    client_max_body_size 100m;

    add_header X-Content-Type-Options "nosniff" always;
    add_header X-Frame-Options "DENY" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;
    add_header Content-Security-Policy "default-src 'self'; style-src 'self' 'unsafe-inline'; script-src 'self'; img-src 'self' data:; connect-src 'self'; form-action 'self'; base-uri 'self'; object-src 'none';" always;

    resolver 127.0.0.11 valid=10s;

    location /static/ {
        alias /app/staticfiles/;
    }

    location / {
        set $upstream http://web:8000;
        proxy_pass $upstream;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```
